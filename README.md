This project is an race summarizer. It will run at 7:00am UTC. 

The project is configured as newsletter operating via buttondown. When the code runs it will generate an entire race summary including driver standings, fastest laps, 
winner tyre compound used, updated championship standings, and updated constructor standings. This summary will be sent to buttondown where subscribed users will be sent 
the email of this race summary. The project makes use of the FastF1 library for its data. It is a community project that can be easily used by anyone.
